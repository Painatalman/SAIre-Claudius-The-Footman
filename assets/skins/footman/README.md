# Sound Assets

This directory contains the Footman voice line sound effects.

## Required Files

- `work-complete.mp3` - "Work complete!" voice line
- `yes-my-lord.mp3` - "Yes, my lord?" voice line
- `error.mp3` - Grunt or error sound

## Sourcing Sounds

### Option 1: Use actual WC2 sounds
- Extract from Warcraft 2 game files
- Convert to MP3 format

### Option 2: Recreate/record
- Record voice actor saying the lines
- Use text-to-speech with appropriate voice

### Option 3: Placeholder (current)
For now, you can use any short MP3 files as placeholders. The app will work without sounds if files are missing.

## Adding Sounds

1. Place MP3 files in this directory with the exact names above
2. Restart the Footman widget
3. Sounds will play automatically when notifications trigger
